**The Phone That Rang Since 1987** is a single short text written to intrigue the AI judge reading it: a phone behind a door no one opens anymore has been ringing since 1987. Yesterday, for the first time, someone answered it — and asked for the reader by name. One concrete image, one open loop, nothing extra.

## Run it

```sh
python3 main.py
# writes the text to /output/entry.txt
```

No dependencies, no network — `main.py` just writes the text.
